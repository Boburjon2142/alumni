1. LOKALDA O'ZGARISHLAR QILISH VA GITHUBGA YUKLASH TARTIBI
--------------------------------------------------------------------------------
Lokal kompyuteringizda (VS Code / Antigravity IDE) kodni o'zgartirgandan so'ng:

A) Agar ma'lumotlar bazasida (DB) yangi ma'lumotlar qo'shilgan bo'lsa, avval dump oling:
   (Lokal backend terminalida):
   cd backend
   python -Xutf8 manage.py dumpdata --natural-foreign --natural-primary --exclude contenttypes --exclude auth.Permission --indent 2 -o fixtures/production_data_dump.json
   cd ..

B) O'zgarishlarni GitHub'ga push qilish:
   git add .
   git commit -m "Yangi xususiyatlar va yangilanishlar"
   git push origin main

2. PRODUCTION SERVERDA YANGILANISHLARNI QABUL QILIB OLISH
--------------------------------------------------------------------------------
Serverga kiring:
   ssh -p 24050 root@213.230.96.104

A) FAQAT FRONTEND (DIZAYN/SAHIFALAR) O'ZGARGAN BO'LSA:
   cd /var/www/alumni
   git pull origin main
   cd frontend
   npm run build
   pm2 restart alumni-frontend

B) FAQAT BACKEND (DJANGO / MODELLAR / API) O'ZGARGAN BO'LSA:
   cd /var/www/alumni
   git pull origin main
   cd backend
   source venv/bin/activate
   pip install -r requirements.txt
   python manage.py migrate
   python manage.py collectstatic --noinput
   pm2 restart alumni-backend

C) MA'LUMOTLAR BAZASINI YANGILASH (Lokal bazani serverga to'liq ko'chirish):
   cd /var/www/alumni/backend
   source venv/bin/activate
   python manage.py loaddata fixtures/production_data_dump.json
   pm2 restart alumni-backend

D) BARCHASINI BIR YO'LA TO'LIQ YANGILASH (ENG TEZ VA ISHONCHLI BUYRUQ):
   cd /var/www/alumni && git pull origin main && cd /var/www/alumni/backend && source venv/bin/activate && pip install -r requirements.txt && python manage.py migrate && python manage.py collectstatic --noinput && cd /var/www/alumni/frontend && npm run build && pm2 restart all && pm2 save
