# Unvon belgilari

Ushbu 9 ta PNG loyiha unvonlari uchun saqlandi. Asl manba:
`assetsss/unvonlar/unvonlar`. Fayllar o'zgartirilmasdan nusxalandi va SHA-256
orqali tekshirildi.

Unvon sluglari bilan bog'lanish: `frontend/lib/recognition-assets.ts`.
Fayl nomlaridagi raqamlar manbadagi tartib; bazadagi unvon tartibi emas.
Rasmi taqdim etilmagan unvonlarga belgi tayinlanmagan.

Assetlarni saqlash amaldagi sahifalar yoki kartalardagi ikonalarni almashtirmaydi.
