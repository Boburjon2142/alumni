Qo‘llanma quyidagi qat’iy standartlarga javob bersin:

1. O‘zgarishlar Xulosasi (Changelog):
   - Ushbu yangilanishda nimalar o‘zgarganini aniq qismlarga ajratib ko‘rsat:
     * Backend (yangi modellar, DB migratsiyalari, API endpointlar, yangi kutubxonalar);
     * Frontend (yangi sahifalar, UI o‘zgarishlari, Next.js build va resurslar);
     * Nginx / Environment / Xavfsizlik sozlamalari.

2. Bitta Blokda Nusxalanadigan (Copy-Paste) Xavfsiz Buyruqlar:
   - Terminalda -bash: !: event not found kabi xatoliklar chiqmasligi uchun buyruqlar ichida xavfli belgilar ishlatilmasin.
   - Barcha zarur qadamlar (git pull, docker compose up -d --build, migrate, collectstatic, kesh tozalash) bitta mantiqiy zanjirda (&&) berilsin.
   - Agar modellar yoki statuslar o‘zgargan bo‘lsa, ma’lumotlar yaxlitligini ta’minlovchi Python shell buyrug‘i qo‘shilsin.

3. Nginx va Domen Sozlamalari (Zarur bo‘lsa):
   - Yangi marshrutlar (routing) yoki statik fayllar uchun Nginx sozlamasida o‘zgarish kerak bo‘lsa, aniq konfiguratsiya va uni qayta yuklash buyrug‘ini ber.

4. Tekshirish va Monitoring (Verification):
   - Deploy muvaffaqiyatli yakunlanganini tekshiruvchi 1 qatorli buyruq (masalan, docker compose ps, API curl tekshiruvi, loglarni ko‘rish).

5. Rollback (Favqulodda ortga qaytish) rejasi:
   - Agar yangi versiyada xatolik yuz bersa, avvalgi ishchi commitga tezkor qaytish buyrug‘i.
